# The Glow Up Salon

## Project Overview
The Glow Up Salon is a Java EE web application designed to manage salon appointments. It allows clients to register, log in, 
book appointments, and view their bookings. The salon owner can log in, view appointments, and confirm bookings.

## Features
- Client registration and login
- Salon owner registration and login
- Appointment booking
- View client appointments
- Owner appointment management
- Confirm appointments
- View appointments stored in a database

## Technologies Used
- Java
- JSP and Servlets
- Enterprise JavaBeans (EJB)
- Java Persistence API (JPA)
- JPQL
- HTML and CSS
- Apache Derby Database
- NetBeans IDE
- GlassFish Server

## Project Structure
- `Webapp` — Web application pages and servlets
- `EJB` — Enterprise JavaBeans and persistence components

## Setup
This project was developed using NetBeans and GlassFish. It requires a compatible Java EE environment and 
Apache Derby database configuration.

The database connection and persistence settings may need to be configured for your local environment before running the application.
